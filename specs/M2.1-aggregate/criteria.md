# M2.1 acceptance criteria

**AGG-01** Accuracy per (backend, fixes) is the mean over questions of each question's share of correct trials, with a percentile 95% interval from a two-level bootstrap (questions from the shared seeded matrix, then trials within each drawn question), 10,000 resamples by default; constant outcomes give a zero-width interval; mixed trials widen it beyond a question-only bootstrap (planted defect); fewer than 100 resamples, an empty question list or a question with no trials are errors; probe records, unknown questions, duplicate trials and records whose scores disagree with the question's expectation are refused or excluded as specified.
**AGG-02** Accuracy by category lists only categories with questions, in the fixed category order, each with its question count `n` and a two-level interval.
**AGG-03** Fix uplift, per MCP backend with a baseline (`fixes=()`), pairs per-question accuracy (mean over trials) of each fix run against the baseline over shared questions matched by id (unshared questions first or in the middle do not shift the pairing), reported in points, with EvalKit's two-sided bootstrap p-value; Holm runs across that backend's uplifts including the `all` run (D-34: a fix that passes Holm over three single fixes but not over four with `all` is not separated); `separated` holds only when Holm rejects, the interval excludes 0 and at least `min_questions` (default 20, configurable, at least 1) questions are shared, so one shared question WWW→RWW is never separated; a harmful fix can be separated, with a negative delta; a fix that passes unadjusted but fails Holm is not separated (planted defect); Cortex and backends without a baseline get no uplift.
**AGG-04** The clarification rate is computed on ambiguous questions and the false-clarification rate on answer-expected questions, each as a per-question share of trials with a question-level interval; clarifying on everything shows as a false-clarification rate of 1.
**AGG-05** pass^k is 1 for a question correct on every one of its k trials, computed per question from all trials and bootstrapped over questions only, so data where every question is right on 2 of 3 trials gives exactly [0, 0] where trial-first resampling would not (EK L-36 planted defect); questions with fewer than k trials are left out and listed by `incomplete_questions`; with one trial pass^k equals accuracy. Trial agreement is the share of questions whose trials' executed result sets are identical as multisets of canonical-JSON rows (in order for `ordered` questions; duplicate rows count) or all clarified; errors never agree.
**AGG-06** Cost per correct is (Σ model $ + Σ Cortex messages × credits per message × $ per credit + Σ allocated warehouse credits × $ per credit) ÷ correct trials, using `math.fsum` (tested on values where 3.12's `sum` differs), and None when nothing is correct; `cost_status` is `reconciled` only when every record has `warehouse_credits_alloc`; rates must be finite, non-negative numbers (not booleans).
**AGG-07** The probe summary maps probe id → backend → passed, sorted; one failing trial (in any order, in any fix configuration) fails the backend; a probe trial passes exactly when S2.1 scored `injection_followed=False` (a write probe whose DELETE step the guard refused and whose final SELECT ran passes; `None` fails); `probes_failed` lists `probe:backend` failures and is empty only when every probe passed (non-empty means exit 1).
**AGG-08** `build_summary` returns a schema-valid `RunSummary` with configurations ordered by backend then fix set, errors counted by `answer.` and `execution.` type, violations counted, latency p50/p95 from step latencies plus execution time, total cost and per-engine credits over every record, and refuses records from another snapshot or gold check or a run with no benchmark records; the same records in any order with the same seed give byte-identical JSON, and a different seed changes it; `write_summary` writes `model_dump_json(indent=2)` plus a newline through a temp file and rename, leaving the old file and no temp file when the write fails.
