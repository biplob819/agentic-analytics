**OSS-04** `docs/quickstart.md`, `docs/reproduce-the-uk-benchmark.md`, `docs/writing-a-dataset-pack.md`, `docs/adding-questions.md` and `docs/cost.md` exist, are linked from the README, describe only behaviour the code has (or name the node that brings it), and every link in them resolves to a repository file.
**OSS-05** CONTRIBUTING (setup, checks, rules, packs), SECURITY (private reporting, key handling, the four read-only layers with `analytics_ro` and `ANALYTICS_RO`), CODE_OF_CONDUCT (with enforcement), bug and feature issue forms, an issue config that disables blank issues and links private vulnerability reporting, and a PR template with the no-paid-call and no-hand-typed-numbers checks.
**OSS-06** PRIVACY.md states there is no telemetry and lists every destination; the set of modules under `src/agentic_analytics` that import a networking or provider library equals the set mapped to those destinations, and the check catches a planted `urllib.request` import inside a function.
**OSS-07** (OWNER D-110: no split; B3.3 is green only after the tag, the publish and a passing release smoke) `docs/versioning.md` states the semver policy (public CLI, results format, pack format, `run.yaml`; deprecation; pack versions); the v0.1.0 tag and the install test against the published package run in `release.yml` once the owner has registered the trusted publisher and tagged (RUN-STATE).
