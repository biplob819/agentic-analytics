# B3.1 — Dashboard

**Wave 3. Depends on:** M2.1, A2.3. **Unblocks:** B3.2, D4.2. **R3.1** wires `agentic-analytics report [--run latest | --example]` to this module.

## Goal
Turn a run's `summary.json` (and, when available, its records and exported traces) into one static, self-contained results page: accuracy by category × backend with intervals and `n`, fix uplift with the "above noise" call, cost per correct next to the clarification pair, a failure explorer, and the stamps that keep the page honest (licence credit, pack, snapshot, as-of, gold mode, cost pending, synthetic example).

## Approach (EvalKit D-42)
- One `index.html` per run: inline CSS, inline SVG charts generated in Python, a few lines of vanilla JS for the explorer filters, stdlib string templates (no Jinja). It loads nothing from the network; the only `http(s)://` strings are plain `<a href>` links (Langfuse, the pack's source) that a reader may choose to follow.
- `summary.vl.json` beside it: Vega-Lite specs of the same charts for anyone who wants interactive exploration. The page never loads them.
- Every chart has `<title>`, `<desc>` and an adjacent data table; marks differ by shape and text label as well as colour; the page has light and dark themes (`prefers-color-scheme`), a skip link, a section nav, visible focus rings, and native `<details>`/`<select>` controls so it is fully keyboard navigable.
- Pure function of its inputs: no clock, no randomness, fixed number formats, sorted iteration. Rendering twice gives byte-identical files. Writes are atomic (temp file then rename, mode 0644).
- Every value from a summary, record, question or pack is scrubbed with the tracing redactor's pattern rules (`Redactor()`, no environment, so the page stays a pure function of its inputs; a redacted URL also loses its user name, which the secret scan would still read as a URL password) and then HTML-escaped; links are emitted only for `http(s)` URLs (Langfuse) and for safe relative paths (exported traces). The written files pass `scripts/secret_scan.py`.
- OWNER D-62: next to every Cortex latency figure (the Cortex row's p50/p95 in the cost panel, the execution time of each Cortex failure) the page says the Snowflake account is in Thailand and Cortex inference crosses to the US. The same note says the figure is SQL execution only: M2.1's `latency_ms` has no Cortex API round trip to add (it is not on the record).

## Outputs
- `agentic_analytics.report`:
  - `render_report(summary, records, out_dir, *, questions=None, gold_sql=None, pack=None, attribution=None, example=False) -> Path` writes `index.html` and `summary.vl.json` and returns the HTML path.
  - `render_html(...) -> str` and `vega_lite_specs(summary) -> dict` (the pure parts).
  - `render.looks_synthetic(summary, records=None, *, placeholder_hashes=True) -> bool`: the run is the bundled example whatever its run id says. Giveaways: the run id `example-synthetic`; the example's fingerprint (config, snapshot and gold-check hashes, all three); an `example-` model snapshot on any record; with `placeholder_hashes`, a hash of one repeated character in the summary or a record. Every rendering entry point (`render_report`, `render_html`, `vega_lite_specs`) stamps on the first three, so a renamed copy of the example cannot drop the SYNTHETIC label; B3.2's publish check refuses on all four.
  - `load_example()` and `render_example(out_dir) -> Path` for the bundled synthetic run (copies its exported traces to `out_dir/traces/` so links resolve).
- `report/format.py` (number formats and labels), `report/charts.py` (inline SVG), `report/templates.py` (CSS, JS, page skeleton), `report/render.py` (sections), `report/example.py`.
- Synthetic labelling: with `example=True` every chart title starts `SYNTHETIC EXAMPLE · `, `summary.vl.json` carries `"synthetic": true` and a synthetic description (each spec's description too), and the example's model snapshots are fictional (`example-agent-a`, `example-agent-b`, `example-cortex`).
- `report/example/`: `summary.json`, `records.jsonl`, `questions.jsonl`, `traces/*.json` — a clearly labelled SYNTHETIC run (run id `example-synthetic`), generated by `tests/report/example_data.py` with factory-style records assembled by A2.3's `assemble` (charts from the executed rows) and `aggregate.build_summary`; a test regenerates it and requires byte equality, so it cannot drift from the code.

## Formats
- Rates and accuracies: percent to one decimal, `62.5%`, interval `95% CI 51.2–73.0%`. Uplift: signed points to one decimal, `+8.0 pts (95% CI +2.0 to +14.0)`. Money: EvalKit's readable dollars, never scientific. Hashes: first 12 hex characters, full value in a `title`.
- Labels: Claude (MCP), GPT (MCP), Cortex Analyst; fixes descriptions, examples, self-check, all.

## Decisions
- The heatmap shows baseline configurations (`fixes=()`), one column per backend; fix runs appear in each backend's dot-and-whisker chart (one shape per fix set) and in the configurations table, so the heatmap stays readable at 3 columns.
- Heat bands (five, by point estimate) are a secondary cue only; each cell prints the point, interval and `n`.
- Uplift marks: ▲ filled triangle up = above noise and helps, ▼ filled triangle down = above noise and hurts (a harmful fix can be separated, D-42 note in M2.1), ○ hollow circle = within noise. The verdict is also written in words beside each row and in the table.
- Licence credit comes from the pack's `attribution` (NFR6): the `pack` argument, else the bundled pack named in `summary.pack` (only when its version matches), else an explicit attribution string; if none is found the page says so in a warning stamp rather than omitting the credit silently.
- Trace links: an exported path `…/<run_id>/traces/<file>.json` links as `traces/<file>.json` (relative to the run folder where `index.html` is written); any absolute path, scheme or `..` segment is shown as text, not linked. Langfuse URLs are linked only when they are `http(s)`.
- The failure explorer lists every incorrect benchmark record (probes are in the probe table). Without records it says so; without questions it shows the id and says text was not provided; without a gold mapping it shows the agent SQL alone.
- Real answer shapes (A2.3 live, L-9): an answer's text keeps its line breaks (`white-space: pre-wrap`) and Markdown is shown as text, never rendered; Cortex's `interpretation` is shown as "Cortex's reading"; the chart line says what A2.3's builder made of the executed rows (`kpi`/`line`/`bar` with rows shown of total, or none: no executed rows / shown as a table), read from the record's `chart.usermeta`. The page does not draw the answer's Vega-Lite chart.
