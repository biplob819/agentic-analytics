# A2.3 acceptance criteria

**ANS-01** `chart_for` returns a Vega-Lite v5 spec with the rows inline, or `None`: one non-null, non-boolean cell gives a `text` mark KPI; one period column (all-`YYYY-MM-DD` or all-`YYYY-MM` valid ISO strings on a UTC scale with a UTC time unit; integers in a column whose name has a `year` or `yr` token, not `years`; or distinct, strictly consecutive integers within 1990–2100 in a column with no id/code/amount-like token; preferring ISO, then the named column, then the left-most) plus one numeric measure gives a `line` sorted by period; one text column plus one numeric measure gives a `bar` sorted by value descending (ties by label), at most 25 bars, the title saying "top 25 of N" with N the true total when cut; empty results, truncated results (`rows_total` above the rows held; below is an error), any null, booleans or nested values, integers beyond 2^53, repeated periods or labels, two numeric non-period columns, more than two columns, or 1×N rows give `None`. The spec holds only JSON scalars, keeps every value it shows exactly as executed (no invented rows), validates as `AnalyticsAnswer.chart`, and for any input never raises, is deterministic and survives a JSON round trip unchanged (property test).
**ANS-02** `assemble` returns a copy with `chart = chart_for(execution.result, …, rows_total=execution.rows_total)` exactly when the answer has SQL and its execution succeeded, re-validated through `model_validate`; with no SQL, no execution or a failed execution the chart is `None` and nothing else changes; an execution of different SQL or on the wrong engine for the backend is an error; the same function serves all three backends; `with_trace` sets `trace_url` and `trace_export` the same way.
**ANS-03** `build_trace` gives one trace per (run, question, backend, fix set, trial) with a deterministic 32-hex trace id; a generation span per model turn with tokens in/out, cost, latency and request id; a tool span per agent step with arguments, rows, error and latency; a Cortex span carrying the answer's `request_id`; an execution span when there is one; every span carries start and end offsets laid end to end, and with the turns given a `final_answer` tool span takes no time of its own (D-70). `NoopTracer.send` returns `None`; `LangfuseTracer` raises `TracingUnavailable` with an install hint when `langfuse` is missing and, on a fake v3-shaped client, opens one root span on the trace id, sets trace name, session, tags and `public`, starts every child span and ends it `latency_ms` after its creation (`end_time` in ns), flushes, and returns the client's trace URL.
**ANS-04** `export_trace` writes `<results>/<run_id>/traces/<qid>-<backend>[-<fixes>]-<trial>.json` (UTF-8, sorted keys, trailing newline, byte-identical on a rewrite) holding question, answer, SQL, steps with arguments, rows and errors, execution summary with a row sample, costs, tokens, spans and `public`, and returns the relative path; path-unsafe run ids are refused; `select_for_export` returns `failure` for every incorrect record and `sample` for a deterministic subset, and samples are public.
**ANS-05** `Redactor` replaces, in strings, every secret env value in raw, JSON-escaped (once and twice) and URL-encoded (once and twice, `+` or `%20`, `/` encoded or kept, any hex case) form (anywhere at 8+ characters, as a whole token when shorter), PEM blocks, Authorization / Proxy-Authorization / X-Api-Key / api_key / Cookie / Set-Cookie and password / passwd / pwd values (also ending a longer name) in any case and quoting, URL query secrets (`token`, `access_token`, `key`, `sig`, `signature`, `password`, and names ending in such a word after `-`, `_` or a camelCase hump, after `?`, `&`, `#` or `;`), bare Bearer/Basic credentials and every `scripts/secret_scan.py` pattern (the copy is pinned equal to the script); in structures, values under *token* (not *tokens*), *secret*, *password*, *passcode*, *credential*, *api_key*, *access_key*, `key`, `authorization` and `cookie` keys, and JSON held inside strings; numbers are never changed. A planted key in the question, the SQL, the answer, step arguments (including JSON inside a string), errors, execution rows or the environment never appears in an export file or in any argument the Langfuse client receives, and a short numeric secret never corrupts a result cell.
