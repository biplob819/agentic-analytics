**REL-01** `headline_block(summary)` returns `<!-- headline:start -->`, one `<img>` whose `src` is the raw URL of `docs/assets/headline.svg`, one paragraph of exactly three sentences, and `<!-- headline:end -->`; the sentences name the backends, the question count, the pack, the trials, the as-of date, "without an LLM judge", the gold mode, and say the 95% intervals are conservative (about 99% coverage); every headline accuracy has its strict, pre-registered score beside it (`97.0% (95% CI 93.0–100.0%; strict 92.0%)`, OWNER D-81) and the third sentence names the four shape equivalences; every decimal prints to one place; a synthetic summary opens with "In the bundled SYNTHETIC example", a real one does not; the fix clause names the largest separated single-fix gain and, beside it, the largest separated harm; the `all` run is never named (Tech Spec §7); single-engine, reconciled, one-trial, no-fix, all-within-noise and only-harmful-fix summaries each still give three one-decimal sentences; `results_block(summary, models, snowflake_region)` gives every configuration but the all-fixes run with accuracy, strict, asking back on ambiguous and on answerable questions, p95 latency with the OWNER D-62 caveat beside Cortex's, cost per correct answer ("estimated" unless reconciled), and each single fix's uplift with its Holm verdict in words; `update_readme` replaces only the text between each marker pair, returns False and leaves the bytes unchanged on a second call, and refuses missing, repeated, reversed or half-present markers; the repository README regenerates byte for byte from the committed `docs/results/summary.json` and `run.json`.

The deploy itself is REL-05 in B3.3 (OWNER D-107).
**REL-03** The README links, with absolute GitHub URLs that resolve to files in the repository, the decision log, the data card, the case study (the "how I built it" note: the owner's role, how Claude Code built it under the node harness, the key decisions), the lessons, the PRD, the Tech Spec, the published summary, the measurement records and the licence, plus EvalKit (GitHub and PyPI `evalkit-harness`), HM Land Registry's Price Paid Data page and the Open Government Licence v3.0; every README image is in `docs/assets/` with alt text, the PNG screenshots (dashboard, demo in saved-answer and passcode modes, OWNER D-60) are under 200 KB and carry pixels only; no README, record or figure text holds a local path or an email; the README's own prose holds no date or schedule (OWNER D-20).
